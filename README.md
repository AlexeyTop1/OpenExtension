# OpenExtension

An open-source, "bring your own AI" browser sidebar extension. Any provider (OpenAI, Anthropic, Gemini, OpenRouter, DeepSeek, Groq, Ollama, LM Studio, or any OpenAI-compatible endpoint), any site.

## Status

Early scaffolding (MVP v0.1 in progress). Chrome/Chromium only for now.

## Development

```bash
pnpm install
pnpm dev
```

Then load `apps/extension/dist` as an unpacked extension at `chrome://extensions`.
